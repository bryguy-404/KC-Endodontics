# Legacy link preservation record

Audit date: August 26, 2026

This record documents the link-preservation decisions made before the former KC Endodontics hosting is retired.

## Site-owned URLs

- All working page paths discovered through the former site were recreated on the replacement site.
- `/procedures/root-canal/endodontic-references/` was linked from the former root-canal content but returned a 404. It has been restored as a maintained reference library.
- `/files/2020/02/PV-referral-form.pdf` was the only linked, site-hosted document found. A new fillable referral PDF is served at the exact same path.
- No rendered link in the replacement site points back to the former hosting. Canonical metadata continues to use `https://www.kcendodontics.com`, which is the intended permanent domain.

## Why third-party PDFs were not copied

The documents belong to outside publishers, and the AAE notes that some discontinued historical newsletters may contain outdated material. Linking to the publisher’s maintained collection preserves access and context without creating an unmaintained or potentially unauthorized duplicate.
